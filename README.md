# راهنمای نشریات علوم انسانی

جست‌وجو و مقایسهٔ ۹۷۰ نشریهٔ علمی از فایل مرجع ۴۹۷ صفحه‌ای. بستهٔ داده شامل یک ردیف یادداشت منبع نیز هست که در نتایج نشریات نمایش داده نمی‌شود.

## داده و پیوندها

نسخهٔ کامل استخراج فایل ارسالی، با همهٔ ۲۲ فیلد هر رکورد (از جمله متن اهداف، مقادیر خام و صفحات منبع)، در `data/catalog-*.txt` ذخیره شده است. `data/catalog-manifest.json` تعداد ردیف‌ها و SHA-256 محتوای بازشده را مشخص می‌کند. مرورگر باید از `DecompressionStream` پشتیبانی کند؛ خطای بارگذاری دادهٔ کامل به‌جای نمایش مجموعهٔ ناقص نشان داده می‌شود. کاربر می‌تواند JSON کامل را از خود سایت دریافت کند؛ برای نشریات، این خروجی دو فیلد مشتق‌شدهٔ `journal_url` و `journal_url_type` نیز دارد.

پیوند برای همهٔ نشریات در رابط موجود است. نشریاتی که صفحهٔ مستقیم آن‌ها شناسایی شده با «وب‌سایت» مشخص می‌شوند؛ برای سایر عنوان‌ها لینک جست‌وجوی دقیق در دامنهٔ ناشر یا وب ارائه می‌شود و به‌عنوان صفحهٔ رسمی معرفی نمی‌شود. نگاشت صفحه‌های مستقیم در `DIRECT_URLS` داخل `app.js` است. نمونه‌های بررسی‌شده: [Elsevier](https://www.sciencedirect.com/journal/learning-and-instruction)، [APA](https://www.apa.org/pubs/journals/edu)، [SAGE](https://journals.sagepub.com/home/RER)، [Taylor & Francis](https://www.tandfonline.com/journals/hedp20)، [Wiley](https://onlinelibrary.wiley.com/journal/10.1111/(ISSN)1365-2729) و [SoLAR](https://www.solaresearch.org/publications/journal/). آمار داوری/نمایه از فایل مرجع است و نباید دادهٔ زنده تلقی شود.

برای تولید دوبارهٔ بسته با فایل JSON استخراج‌شده:

```bash
python3 scripts/build_catalog.py /path/to/magazines.json
```

خروجی بدون وابستگی خارجی تولید می‌شود و برابری داده‌ها با SHA-256 قابل بررسی است.

## اعتبار و رابط

«دربارهٔ ما» عنوان فهرست و نام گردآورنده و تنظیم‌کننده را از تصویر صفحهٔ عنوان فایل مرجع نقل می‌کند. حسین کریمی تهیه‌کنندهٔ وب‌اپ معرفی شده است؛ این نقش از نقش پدیدآورندگان منبع جداست.

نشان دانشگاه از همان تصویر صفحهٔ عنوان ارسالی در `assets/source-title-page.png` نمایش داده می‌شود. ناحیهٔ نشان با CSS در بخش «دربارهٔ ما» دیده می‌شود و خود فایل تصویر بدون تغییر نگهداری شده است؛ بنابراین نوشته و شکل نشان دقیقاً مطابق مرجع می‌ماند.

فونت متغیر Vazirmatn از [مخزن رسمی](https://github.com/rastikerdar/vazirmatn) در `assets/fonts/` نگهداری می‌شود و فایل `OFL.txt` مجوز SIL OFL 1.1 آن است. بارگذاری فونت به سرویس بیرونی وابسته نیست. دادهٔ نشریات پیش از نمایش با تعداد ردیف‌ها و در مرورگرهای دارای Web Crypto با SHA-256 manifest کنترل می‌شود. ذخیره‌سازی علاقه‌مندی‌ها اختیاری است و غیرفعال بودن آن مانع بارگذاری سایت نمی‌شود.

## پیشنهاددهندهٔ نشریه

در صفحهٔ اصلی، تب «جست‌وجوی نشریات» فیلترها و نتایج فهرست را نشان می‌دهد و تب «پیشنهاد نشریه» فرم مقاله را در اختیار می‌گذارد. پیوند مستقیم `#recommender` نیز این تب را باز می‌کند.

فرم «پیشنهاد نشریه» عنوان، چکیده و کلمات کلیدی مقاله را در خود مرورگر با **عنوان، حوزهٔ علمی، حوزهٔ پوشش و اهداف نشریات** تطبیق می‌دهد. `recommender.js` متن فارسی و انگلیسی را یکدست می‌کند، واژه‌های عمومی را کنار می‌گذارد و برای چند اصطلاح متداول معادل فارسی/انگلیسی دارد. کلیدواژه‌ها و عنوان مقاله وزن بیشتری از چکیده دارند؛ تطابق در عنوان و حوزهٔ علمی نشریه وزن بیشتری از اهداف بلند آن می‌گیرد. خروجی تا ۱۰ عنوان متمایز را به‌ترتیب ارتباط موضوعی، همراه با دو فیلد مؤثر در پیشنهاد و بدون امتیاز عددی نمایش می‌دهد. اگر شواهد کافی نباشد، نتیجه‌ای پیشنهاد نمی‌کند.

ترتیب پیشنهادها سنجه‌ای واژگانی بر اساس دادهٔ موجود است و معادل ارزیابی متخصص، احتمال پذیرش یا مدل معنایی چندزبانه نیست. متن مقاله به سرور فرستاده یا در مرورگر ذخیره نمی‌شود.

## توسعه و آزمون

منطق خالص جست‌وجو، فیلتر و مرتب‌سازی در `catalog-core.js` از رابط مرورگر جداست و همراه با پیشنهاددهنده و بارگذاری کامل فهرست آزمون می‌شود. برای اجرای همهٔ آزمون‌های بدون وابستگی خارجی، Node.js 18 یا جدیدتر کافی است:

```bash
npm test
```

همین مجموعه در هر push و pull request با GitHub Actions اجرا می‌شود.

## Deploy on Vercel

این پروژه یک سایت استاتیک است و Build Step ندارد.

1. ریپوی `Hhhkarimi/JorFinder` را در Vercel Import کنید.
2. Framework Preset را روی **Other** بگذارید.
3. Root Directory را روی `./` نگه دارید.
4. Build Command و Output Directory را خالی بگذارید.
5. Deploy را بزنید.

فایل `index.html` در ریشه قرار دارد. داده‌های کامل از قطعات `data/catalog-*.txt` خوانده می‌شوند؛ تعداد قطعات از manifest گرفته می‌شود. فایل‌های آزمایشی و مجموعهٔ خلاصهٔ قدیمی حذف شده‌اند.
