# JorFinder / مجله‌یاب

جست‌وجو و مقایسهٔ ۹۷۰+ نشریهٔ علمی.

## Deploy on Vercel

این پروژه یک سایت استاتیک است و Build Step ندارد.

1. این ریپو را در Vercel Import کنید.
2. Framework Preset را روی **Other** بگذارید.
3. Build Command را خالی بگذارید.
4. Output Directory را خالی بگذارید.
5. Deploy را بزنید.

فایل `index.html` در ریشهٔ پروژه است و داده‌ها از پوشهٔ `data/` بارگذاری می‌شوند. متن‌های بلند اهداف و چشم‌انداز به‌صورت lazy-load از فایل‌های `aims-*.json` خوانده می‌شوند.
